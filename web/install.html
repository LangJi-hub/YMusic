安卓手机检查中

装好后桌面上会出现图标，点开就能用。以后加功能会在 App 里提示，点一下就更新。

下载安卓客户端 先用网页版
安装提示选择「允许安装未知应用」即可

苹果 iPhone / iPad

苹果不允许直接装安装包，用 Safari 添加到主屏幕，效果和 App 一模一样。

  1. 用 Safari 打开本页（微信里打开请先点右上角「在 Safari 中打开」）
  2. 点底部中间的 分享按钮（方框带向上箭头）
  3. 向下找到 「添加到主屏幕」 → 点右上角 「添加」
  4. 回到桌面，点新出现的 YMusic 图标 即可全屏使用
